# SES Attorneys website (sesattorneys.com)

Static website for SES Attorneys, Pune. Plain HTML, CSS and JavaScript, generated by a small build script. No frameworks or packages needed, only Node.js.

## Folders

```
src/
  pages/            Page content (home, about, practice-areas, practice-area, careers, contact, disclaimer, 404)
  static/
    js/data.js      ALL firm details, practice area text, slides, disclaimer text (edit this first)
    js/main.js      Interactive parts: menu, slider, forms, WhatsApp widget, disclaimer pop-up
    css/            styles.css and fonts.css
    fonts/          Self-hosted fonts
    images/         Photos (CREDITS.md lists sources); images/thumbs/ holds the smaller card versions
    favicon.svg, CNAME, .nojekyll
build.js            Builds the finished site into docs/
serve.js            Local preview server
docs/               GENERATED. This is what GitHub Pages publishes. Don't edit by hand.
package.json        Shortcuts: npm run build, npm start, npm run dev
```

The design reference files (`.dc.html`) are kept outside this repository, in `../Test workings (1)/`.

## Everyday workflow

1. Edit files in `src/` (most text lives in `src/static/js/data.js`).
2. Build: `node build.js` (or `npm run build`)
3. Preview: `node serve.js` (or `npm start`), then open http://localhost:8080. `npm run dev` does both.
4. Commit and push, including the `docs/` folder.

## Page addresses

| Page | URL |
|---|---|
| Home | `/` |
| About | `/about/` |
| Practice areas overview | `/practice-areas/` |
| Each practice area | `/practice-areas/<slug>/` (slugs are set in data.js, for example `real-estate`) |

| Contact | `/contact/` |
| Disclaimer | `/disclaimer/` |

The build also writes `sitemap.xml`, `robots.txt` and `404.html`.

## Publishing on GitHub Pages (free)

1. Create a **public** repository and push this whole project.
2. **Settings > Pages**: Source **Deploy from a branch**, Branch **main**, folder **/docs**.
3. DNS at your domain registrar for sesattorneys.com:
   - Four **A** records for `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - **CNAME** for `www` pointing to `<your-github-username>.github.io`
4. Once GitHub confirms the domain, tick **Enforce HTTPS**.
